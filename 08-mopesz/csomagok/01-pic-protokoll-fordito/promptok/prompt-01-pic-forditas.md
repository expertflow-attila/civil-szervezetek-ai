# Prompt #01 — PIC-protokoll fordítás

```
Fordítsd ezt a kórházi PIC-protokoll szöveget szülői magyar nyelvre:

[CSATOLT PROTOKOLL itt]

Output formátum:
- Címsor (rövid, vonzó — pl. "Anyatej a koraszülött babának")
- "Miért fontos" — 2-3 mondat
- "Mit jelenthet" — lista (3-5 pont)
- "Mit csinálj" — lista (lépésekben, vizuális)
- "Mikor beszélj a nővérrel / orvossal" — 1-2 példa

Szabályok:
- Rövid mondatok (12-15 szó)
- Szakkifejezés zárójelben az orvosi terminussal: "bélgyulladás (NEC)"
- Empatikus, nem ijesztgető hangnem
- A KORE Pici Füzet stílusa (ha a Project-ben van minta)
```

## Variáns: angol → magyar nemzetközi anyag

```
Fordítsd ezt az ANGOL koraszülött-anyagot magyar szülői nyelvre:

[CSATOLT ANGOL TEXT]

Plusz feladat:
- Magyar koraszülött-statisztikákat is mellékeld (KSH-hivatkozással)
  ahol a magyar helyzet eltér
- Magyar kórházi-rendszer kontextusban: PIC-osztály = NICU
```
