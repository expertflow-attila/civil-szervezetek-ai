# Prompt #01 — Általános keresés

**A prompt:**

```
Keress az archívumban: [TÉMA / KULCSSZÓ].

Adj 3-5 legrelevánsabb anyagot:
- Fájlnév + 1-2 mondatos összefoglaló
- Frissítve mikor (ha >3 év, jelöld ⚠️ elavult)
- Melyik a leg-naprakészebb / leghasználhatóbb

Záró: ajánlás melyiket olvassam először.
```

## Példák

```
Keress: "válási mediáció lépései"
```

```
Keress: "család átmeneti otthonok elérhetősége vidéken"
```

```
Keress: "családi adókedvezmény 2026-os szabályok"
```

```
Keress: "önkéntes-onboarding mediációs csoporthoz"
```
