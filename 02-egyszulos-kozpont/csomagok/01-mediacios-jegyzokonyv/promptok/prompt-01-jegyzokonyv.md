# Prompt #01 — Mediációs jegyzőkönyv strukturálás

**A prompt** (Claude Desktop új beszélgetés első üzenetébe):

```
Strukturáld ezt a mediációs ülés-átiratot az Egyszülős Központ
formátumába (a system-prompt szerint).

Ülés dátuma: 2026-04-12
Ülés-szám: 2
Mediátor: [HIÁNYZIK: aláírás]

[CSATOLT TRANSCRIPT itt]

Output: a "# Mediációs jegyzőkönyv — [dátum]" formátumú struktúra,
semleges hangnemmel, anonimizálva.
```

## Variáns: gyász-támogató csoport jegyzőkönyv

```
Strukturáld ezt a gyász-támogató csoport-ülés-átiratát:
- 8 résztvevő (mind anonim — A, B, C, D, ...)
- Téma: gyermek-elvesztés
- Ülés-szám: 5

Output: nem személy-szintű jegyzőkönyv, hanem TEMATIKUS összefoglaló:
- Felmerült témák
- Csoport-dinamika megfigyelése (csoport-vezetői)
- Következő ülés napirendje
- Egyéni follow-up-jelölésekel (csak akkor ha veszélyjelzés)
```
