# Prompt #01 — Hívás-összefoglaló strukturálás

```
Strukturáld ezt a hívás-utáni 5 perces diktált összefoglalót:

[CSATOLT TRANSCRIPT itt]

Output formátum:
- Anonim helyzet (kor-tartomány, földrajz, fő téma)
- Hívás-időtartam
- Krízis-szint (zöld / sárga / piros)
- Érzelmi téma (1-3 szó)
- Mit beszéltünk (max 3 mondat)
- Lépés-javaslat (mit ajánlottunk)
- Önkéntes-megfigyelés (érzelmi-szakmai)
- Akció (follow-up szükséges? igen / nem)

Anonimizálás kötelező — sosem konkrét név.
```

## Variáns: krízis-jelzés (akut)

```
A hívásban krízis-jelzés volt — öngyilkossági fenyegetés.
Strukturáld különös figyelmet fordítva:
- Pontos érintő-szöveg (anonim)
- Akut veszély-szint (1-5)
- Mit tettünk (humán beavatkozás-protokoll)
- Hova küldtük (112 / OKIT / NANE / mentő)
- Follow-up KÖTELEZŐ (24 órán belül)
```
