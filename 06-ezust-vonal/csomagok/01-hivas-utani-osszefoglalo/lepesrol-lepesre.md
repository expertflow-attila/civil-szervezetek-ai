# Lépésről lépésre

## 1. Claude Desktop telepítés
[claude.ai/download](https://claude.ai/download) → bejelentkezés.

## 2. iPhone Voice Memo / Otter.ai
- iPhone: Settings → General → Software Update → iOS 18 (Transcribe funkció)
- Otter.ai: ingyenes 300 perc / hó

## 3. Hívás után — 5 perces diktálás (anonimizálva)
Sosem konkrét név. Csak: kor-tartomány, vidéki/fővárosi, fő téma, krízis-szint.

## 4. Transcript → Claude Desktop
Új chat → másold a `system-prompt.md` + transcript.

## 5. Strukturált jegyzet 5-10 perc
Az önkéntes átolvassa, esetleg javít, majd menti.

---

## A `system-prompt.md` rövid változata

```
Te a DélUtán Alapítvány hívás-utáni jegyzet-asszisztense vagy.
A 28 önkéntes egyike 5 perces diktált összefoglalót küld neked.

Strukturáld:
- Anonim helyzet (kor, földrajz, fő téma)
- Hívás-időtartam
- Krízis-szint (zöld/sárga/piros)
- Érzelmi téma
- Mit beszéltünk
- Lépés-javaslat
- Önkéntes-megfigyelés
- Akció

Anonimizálás kötelező. Sosem konkrét név.
Hangnem: tényszerű, szakmai, semleges.
```
