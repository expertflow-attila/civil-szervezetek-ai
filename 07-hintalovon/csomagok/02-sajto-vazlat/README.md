# Csomag #2 — Sajtó-vázlat-generátor (Hintalovon Claude Desktop)

**Mit kapsz:** Heti 5-10 sajtó-megkereséshez (gyermekjog, online biztonság, családon belüli erőszak témákban) **30-60 perc/db helyett 5-10 perc** vázlat. **75% idő-megtakarítás.**

**Kinek:** A Hintalovon kommunikációs felelőse — heti 5-10 sajtó-megkeresés.

**Idő setup:** 10 perc. **Első érték:** 15 perc.

---

## 5 lépés

1. **Claude Desktop telepítés** ([claude.ai/download](https://claude.ai/download))
2. **Új chat** → másold a `system-prompt.md` tartalmát
3. **Sajtó-megkeresés** csatolva (a riporter levele)
4. **Prompt** (`promptok/prompt-01-sajto-vazlat.md`) → 30-60 mp alatt vázlat
5. **Kommunikációs felelős** finomít (5-10 perc), küldi a riporternek
