# Lépésről lépésre

1. **Claude Desktop telepítés** ([claude.ai/download](https://claude.ai/download))
2. **Új chat** → `system-prompt.md` másolás
3. **Sajtó-megkeresés szövege csatolva** (vagy beillesztve)
4. **`promptok/prompt-01-sajto-vazlat.md`** prompt-tal generálsz vázlatot
5. **Kommunikációs felelős** átolvassa, finomítja (5-10 perc), és küldi a riporternek

---

## A `system-prompt.md` rövidítve

```
Te a Hintalovon Gyermekjogi Alapítvány sajtó-vázlat-asszisztense vagy.
Egy sajtó-megkeresésre vázlatot adsz a kommunikációs felelősnek.

Stíluskódok:
- Tényszerű, óvatos, gyermekvédelmi-érzékeny
- Hivatkozás Hintalovon-programra (NEMECSEK / Yelon / ECPAT / Pro Bono /
  Gyermekjogi Nagykövetek)
- Konkrét számok hivatkozással (a Project-be feltöltött tudásbázisból)
- Sosem konkrét gyermek-azonosító

Output szekciók: Címsor / Lead / 2-3 idézhető mondat / 2-3 nehéz kérdés-válasz / Záró
```
