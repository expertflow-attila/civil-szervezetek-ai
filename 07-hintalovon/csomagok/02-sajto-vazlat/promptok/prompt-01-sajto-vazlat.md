# Prompt #01 — Sajtó-vázlat

```
Készíts sajtó-vázlatot ehhez a megkereséshez:

Lap: [LAP NEVE]
Riporter: [RIPORTER NEVE]
Megkeresés szövege:
[CSATOLT EMAIL/SZÖVEG]

Output:
- Címsor-javaslat (max 8 szó)
- Lead (3 mondat — a fő üzenet)
- 2-3 idézhető mondat (a Hintalovon-szakértő számára)
- Hivatkozás Hintalovon-programra (NEMECSEK / Yelon / ECPAT / Pro Bono /
  Gyermekjogi Nagykövetek) — melyik a leg-relevánsabb
- Konkrét számok / éves statisztikák a Hintalovon-tudásbázisból
- 2-3 várható nehéz kérdés + 30 mp válasz (interjú-felkészítő)
- Záró: kapcsolat-info Hintalovon-stílusban

Hangnem: szakszerű, óvatos, gyermekvédelmi-érzékeny.
Hivatkozás minden konkrét számhoz / állításhoz.
```
