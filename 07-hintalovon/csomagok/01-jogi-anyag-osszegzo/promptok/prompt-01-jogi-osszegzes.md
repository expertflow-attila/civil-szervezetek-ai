# Prompt #01 — Jogi anyag-összegzés

**A prompt** (Claude Project chat-be, miután a jogi PDF/DOCX feltöltésre került):

```
Olvasd el a feltöltött jogi anyagot ([CÍM]).

Készíts:

1. **Vezetői összefoglaló (1 oldal)**:
   - Mi az anyag fő üzenete (3-4 mondat)
   - Mi változik a jelenlegi gyakorlathoz képest
   - Hintalovon szempontjából melyik 3 pont a legfontosabb

2. **Sajtó-vázlat (1/2 oldal)**:
   - Címsor (max 8 szó)
   - Lead (3 mondat)
   - 2-3 idézhető mondat (a Hintalovon-szakértő számára)
   - Záró: kapcsolat-info Hintalovon-stílus

3. **Hatás-elemzés (1 oldal)**:
   - Gyermekjogi szempontok érintettsége
   - Mely Hintalovon-program érinti (NEMECSEK / Yelon / ECPAT / Pro Bono)
   - Reformkezdeményezés-javaslat

4. **5 kapcsolódó kérdés** további kutatáshoz

Hivatkozás kötelező — minden állításhoz oldalszám az eredetiből.
```
