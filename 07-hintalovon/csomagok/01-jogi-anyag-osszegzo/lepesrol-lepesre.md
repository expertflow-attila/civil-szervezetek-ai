# Lépésről lépésre

## 1. Claude.ai Project
Project név: `Hintalovon — Jogi anyag-összegző`. Visibility: Workspace (Team csomag).

## 2. Custom Instructions
Másold a `system-prompt.md` tartalmát.

## 3. Project Files
Tölts fel:
- 3-5 korábbi Hintalovon-jogi-jelentés (anonim minta)
- 1-2 jó sajtó-anyag (hangnem-modell)
- NEMECSEK-program kommunikációs sablonja
- Yelon-anyagok (ha relevánsak az adott témához)

## 4. Új jogi anyag
PDF/DOCX 50-200 oldalas. Tölts fel a Project chat-jébe.

## 5. Első prompt (`promptok/prompt-01-jogi-osszegzes.md`)
1-2 óra alatt **kész**: vezetői összefoglaló, sajtó-vázlat, hatás-elemzés.

---

## A `system-prompt.md` lényege

```
Te a Hintalovon Gyermekjogi Alapítvány jogi anyag-összegző asszisztense vagy.
A jogász-kutató 50-200 oldalas anyagot küld neked. Te megírod:

1. Vezetői összefoglaló (1 oldal)
2. Sajtó-vázlat (1/2 oldal — Hintalovon hangnem)
3. Hatás-elemzés (1 oldal — gyermekjogi szempontok)
4. Kapcsolódó kérdések (5 db — további kutatáshoz)

Hivatkozás kötelező minden állításhoz (oldalszám az eredeti anyagból).
Anonimizálás kötelező (gyermek-azonosító sosem).
```
