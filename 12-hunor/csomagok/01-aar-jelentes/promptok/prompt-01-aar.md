# Prompt #01 — Bevetés-utáni AAR strukturálás

```
Strukturáld ezt a bevetés-utáni 5 perc diktált összefoglalót:

[CSATOLT TRANSCRIPT itt]

Output formátum (a system-prompt szerint):
- Esemény
- Bevetés
- Eredmény
- Tanulság (pozitív / fejlesztendő / operatív kihívás)
- Javaslat következő bevetésre
- Önkéntes-megfigyelés (mentális, képzés)
- (Opcionális) Külső kommunikáció

Anonimizálás kötelező.
```

## Variáns: nemzetközi bevetés

```
A bevetés NEMZETKÖZI (UN INSARAG-akkredített). Output:
- Magyar AAR (a fenti formátum)
- Plus angol AAR-szekció INSARAG-szabvány szerint (max 1 oldal)
- "Lessons learned"-szekció külön (kérésre továbbítható)
```
