# Prompt #01 — Jogi anyag NANE-szempontú összegzés

```
Olvasd el a feltöltött jogi anyagot ([CÍM]).

Készíts:

1. **Vezetői összefoglaló (1 oldal)**:
   - Mi az anyag fő üzenete (3-4 mondat)
   - Mi változik a jelenlegi gyakorlathoz képest
   - NANE-szempontból a 3 legfontosabb pont (családon belüli erőszak,
     gyermekvédelem, áldozat-segítés)

2. **Reformkezdeményezés-vázlat**:
   - Cél (konkrét, mérhető)
   - Stratégia (3-4 lépéses lobbi)
   - Kockázat (politikai-óvatos)
   - Időbeli ütemezés

3. **Sajtó-anyag-vázlat (1/2 oldal — NANE-stílus)**:
   - Címsor (max 8 szó)
   - Lead (3 mondat)
   - 2-3 idézhető mondat
   - Forrás-hivatkozás

4. **5 kapcsolódó kérdés** további kutatáshoz

Hivatkozás kötelező — oldalszámmal.
Anonimizálás — sosem konkrét eset.
```
