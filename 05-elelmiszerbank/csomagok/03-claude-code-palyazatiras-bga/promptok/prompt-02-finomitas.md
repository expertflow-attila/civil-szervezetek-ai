# Prompt #02 — Iteratív finomítás (a kapott pályázat-szekciók módosítása)

**Mire jó:** Miután a Claude Code 1. verziót adott, te átolvasod, és kérsz konkrét módosítást szekciónként.

**Miért hasznos:** Az 1. verzió sosem tökéletes. Iteráltatva 5-7 körön át kapsz **publikálható** pályázat.

**Mikor használd:** Miután a teljes 1. verzió kész (palyazatok/2026-bga-...md fájlban).

---

## Szekció-szintű finomítások

### Egy szekció átírása

```
A 4. szekció (Módszer / megvalósítás) túl elvont. Konkretizáld 5 alfejezettel:
1. Hogyan toborzunk vidéken (helyi újság, faluközösség, iskolai partnerség)
2. Önkéntes-onboarding workflow
3. Heti gyakorlat-rendszer
4. Mentor-rendszer (új önkéntes mellé tapasztalt)
5. Mérés és visszacsatolás

Mindegyiknek 1-2 bekezdés legyen.
```

### Költségvetés-finomítás

```
A költségvetés-szekciót részletezzed. 8 millió Ft keret, ebből:
- 50%: új önkéntes képzése (vidéki utazás-támogatás, 2-napos képzés)
- 25%: 2 új koordinátori pozíció (félállás, 6 hónap)
- 15%: szoftver-eszközök (Claude for Nonprofits skálázás, SmartFront fejlesztés)
- 10%: dokumentáció, anyagok

Mindegyik tételhez 2-3 mondatos indoklást.
```

### Hatás-mérés

```
A 7. szekció (Mérhető hatás) konkretizáld:
- Önkéntes-szám: 60 → 100+ (mérhető: havonta jelentés)
- Mentett tonna éves: 10 685 → 12 500 (+17%)
- Érintett emberek: 243 919 → 280 000+
- CO2: 27,5M kg → 32M kg
- Vidéki raktár-átfutás: 36 órás → 24 órás (mérhető: SmartFront timestamp)

A számokat indokold a 4 raktár ütemezésével — pl. miért 12 500 tonna a reális becslés.
```

### Kockázat-szekció

```
A 9. szekció (Kockázatok) most általános. Adj konkrét magyar civil-szektor
kockázatokat:
- Inflációs nyomás (önkéntes-megtartás)
- Pályázati csúszás (állami támogatás kifizetése)
- Áruházi partner-csökkenés (egy lánc kivonul)
- DPO-szabályozás változása (GDPR-frissítés)
Mindegyikhez 1-1 mitigációs javaslat.
```
