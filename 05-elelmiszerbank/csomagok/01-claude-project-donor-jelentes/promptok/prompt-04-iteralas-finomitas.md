# Prompt #04 — Iteratív finomítás (a kapott riport módosítása)

**Mire jó:** Miután a Claude megírja az 1. verziót, te átolvasod, és kérsz konkrét módosítást. Ezek a leggyakoribb finomítási promptok.

**Miért hasznos:** Az 1. verzió sosem tökéletes. Az AI-t **iteráltatva** percek alatt kapsz publikálható verziót.

**Mikor használd:** Az 1. verzió elolvasása után.

---

## Hangnem-finomítás

```
A 3. bekezdés túl marketinges. Írd át tényközpontibbá.
```

```
Túl száraz a hatás-történet. Adj 1 érzelmi mondatot a végéhez,
de NE használj giccses kifejezéseket.
```

## Szám-finomítás

```
A CO2-számítás kerek számokra hozza. Most "1 752,3 kg" — legyen "kb. 1 800 kg".
```

```
A "Top 3 áruház" listában a Debrecen 262,7 kg helyett 287 kg-ot mutass —
a forrás-fájlt is javítsd ennek megfelelően.
```

## Tartalom-bővítés

```
Adj még 1 záró mondatot, amelyben **konkrét következő közös akciót** javasolsz
a Tesco CSR-csapatának (pl. húsvéti Adományok Hete).
```

```
Hivatkozz a 2024-es éves teljesítményünkre (10 685 tonna) — egy mondatban
mutasd, hogy a Tesco hozzájárulása az országos eredményünkhöz hány %.
```

## Kihagyás

```
A "Pici Füzet"-utalás nem releváns ennél a donornál — vedd ki.
```

```
A Tesco-CSR-csapat nem szereti a "magyar adminisztratív" hangnemet —
egyszerűsítsd le, írd közvetlenebbre.
```

## Anonimizálás-ellenőrzés

```
Ellenőrizd a riportban a partner-szervezet-neveket: minden anonim?
("fovarosi-gyermekellato-A" vagy hasonló) — ha találsz konkrét nevet,
javítsd ki.
```
