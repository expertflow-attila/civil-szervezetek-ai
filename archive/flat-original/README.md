## Bevezetés sorrendje (javasolt)

1. **Vezetői megbeszélés** — `01-04` exec summary-k egyikét bemutatni a vezetésnek (15 perc)
2. **Claude for Nonprofits jelentkezés** — `06` levélsablon kitöltése + benyújtása (átfutás 2-4 hét)
3. **AI munkagép setup** — `07` config alapján 1 nap alatt
4. **Stáb-tréning** — `05` prompt-csomag begyakorlása (2 órás workshop)
5. **30 napos pilot** — válasszunk 1 use case-t a vezetői összefoglalóból
6. **Mérés és skálázás** — a teljes 90 napos tervhez lásd: `~/.claude/plans/szia-abban-szeretn-m-k-rne-lazy-hammock.md`
