# Lépésről lépésre — Helyi vezető Project setup

**Idő összesen:** 8-10 óra (egyszeri Project-építés). **Idő első értékig:** 1 hét (10 fős pilot).

---

## 1. Claude.ai → új Project

[claude.ai](https://claude.ai) → **Projects** → **+ New Project**.
Név: **`NOE — Helyi vezető assistant`**.
Visibility: **Workspace** (Team csomagban).

## 2. Custom Instructions

⚙️ Settings → Custom Instructions → **másold a `system-prompt.md` tartalmát**. Save.

## 3. Project Files feltöltés

Tölts fel minden szervezeti dokumentumot, amit a 250 vezető kérdezhet:
- Alapító okirat (csak a nyilvános rész)
- ÁSZF
- Programszervezési útmutató (a `sample-fajlok/programszervezesi-utmutato.md` minta)
- Kedvezmény-szabályzat
- Tagdíj-rendszer
- Sablon-meghívók (családi nap, közgyűlés)

> 💡 8-10 órás munka **egyszer** — utána a Project készen áll.

## 4. Pilot 5-10 helyi vezetőnek

Hívj meg 5-10 helyi vezetőt **4 hetes pilot-ra** — Workspace-be (ha Team csomagod van) vagy `Share` linkkel (Pro-fiókkal).

## 5. Heti review

A 4 pilot-héten **heti meeting** a központi koordinátorral:
- Mit kérdeznek?
- Hol akad el?
- Mit kell még feltölteni?

Negyedik hét után **mind 250 vezetőnek** elérhetővé válik.
