# Prompt #02 — Tagsági / adminisztratív kérdés

**Mire jó:** Új tagcsalád felvétele, NOE-kártya, tagdíj-utalás, kedvezmény-rendszer kérdéseire ad sablon-választ.

**Mikor használd:** Bármely vezetőként, amikor tagsági ügyben vagy bizonytalan.

---

## A prompt

```
Vagyok a NOE [VÁROS] helyi szervezet vezetője.

Kérdés: [TAGSÁGI KÉRDÉS]

Pl.: "Hogyan veszek fel egy 4-gyermekes új családot, akinek a 2 kisebb még
nem született magyar állampolgár?"

Adj sablon-választ a Project-be feltöltött dokumentumok alapján:
- Konkrét eljárási lépések
- Szükséges dokumentumok
- Felelős központi kontakt (ha kell)
- Hivatkozás a Project-be feltöltött dokumentumra
```

---
