# Prompt #01 — Helyi program-szervezési kérdés

**Mire jó:** A 250 helyi vezető tipikus szervezési kérdéseire ad sablon-választ.

**Hasznos:** Most a központi iroda 1.5-2.5 órát napi telefon-időt fordít ezekre. AI-vel **5 perces önkiszolgáló válasz**.

**Mikor használd:** Bármely helyi vezetőként, amikor szervezést tervezel.

---

## A prompt — másold be a Project chat-be

```
Vagyok a NOE [VÁROS] helyi szervezet vezetője.

Kérdés: Hogyan szervezek [ESEMÉNY] [N] főre [KÖLTSÉGVETÉS] Ft-ból
[VÁROS / RÉGIÓ]-ban?

Adj 3 alternatívát különböző költségvetéssel, mindegyikhez:
- Konkrét lépések
- Becsült költség
- Felelős sablon-szakember (önkormányzati / partneri / önkéntes)
- Hivatkozás a Project-be feltöltött dokumentumra
```

---

## Példák

### Családi nap

```
[ESEMÉNY] = családi nap, [N] = 80, [KÖLTSÉGVETÉS] = 200e, [VÁROS] = Veszprém
```

### Mikulás-ünnepség

```
[ESEMÉNY] = Mikulás-ünnepség, [N] = 60 gyerek, [KÖLTSÉGVETÉS] = 150e, [VÁROS] = Békéscsaba
```

### Kirándulás-jelentkezés

```
[ESEMÉNY] = buszos kirándulás Lillafüredre, [N] = 40 fő, [KÖLTSÉGVETÉS] = 240e, [VÁROS] = Borsod
```
